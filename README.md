# فروشگاه محصولات (Nuxt 4 Front-End Test)

این پروژه با هدف پیاده سازی یک نمونه تست از صفحه محصولات یک وب اپ فروشگاهی (صفحه محصولات همراه با فیلتر) از UI آماده
همراه با API تستی با تمرکز روی بهینه سازی و ساختار تمیز آماده شده است.

## پیش‌نیازها

| ابزار           | نسخه پیشنهادی |
|-----------------|---------------|
| Node.js         | 24.21.0 LTS   |
| Package Manager | pnpm          |

## نصب و اجرا

```bash
# نصب وابستگی‌ها
pnpm install

# اجرای محیط توسعه
pnpm dev

# بیلد نسخه پروداکشن
pnpm build

# پیش‌نمایش بیلد پروداکشن
pnpm preview

# اجرای تست‌ها
pnpm test

# lint
pnpm lint
```

## متغیرهای محیطی

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید:

```bash
cp .env.example .env
```

## استک فناوری

- 💪  **Nuxt 4** — فریم‌ورک اصلی (SSR + Nitro)
- 🦾  **TypeScript** — با حالت `strict`
- 🎨  **Tailwind CSS v4** — استایل‌دهی با تم اختصاصی (رنگ، فونت، فاصله‌گذاری بر اساس Figma)
- 😃 **Pinia** — مدیریت state برای فیلترها (و در صورت نیاز، سبد خرید)
- 🎨  **@nuxt/image** — بهینه‌سازی و لود تنبل تصاویر
- 🦾 **ESLint + Husky + lint-staged** — کیفیت و یکدستی کد قبل از هر کامیت

## Git Commit Convention

کامیت‌ها به‌صورت مرحله‌به‌مرحله و بر اساس فیچر انجام می‌شوند:

```
chore: ...   تنظیمات اولیه، نصب پکیج‌ها
feat: ...    افزودن قابلیت جدید
fix: ...     رفع باگ
perf: ...    بهبود عملکرد
style: ...   تغییرات ظاهری بدون تغییر منطق
test: ...    افزودن یا اصلاح تست
docs: ...    مستندات
```
